# 投影片生成 - 自訂需求

此檔案定義生成投影片時的額外需求。
系統會自動載入此檔案（除非使用 --no-custom 跳過）。
**請根據你的研究領域修改此檔案。**

---

## 簡報風格

- 使用清晰的標題層次結構
- 每張投影片控制在 3-5 個要點
- 適當使用視覺化元素（流程圖、表格、對比圖）

## 內容呈現

- 粗體僅用於論文關鍵詞（keywords）及其近義術語，每張投影片最多 1-2 個；結論重要性以位置和句式表達，不用粗體
- 數據結果使用圖表輔助說明
- 複雜概念分解為步驟式說明

## 語言風格

- 使用學術但易懂的語言
- 專業術語首次出現時附上英文原文
- 避免過度冗長的句子

## 學術報告特殊要求

- 明確標註研究方法和樣本大小
- 統計結果使用標準格式（p 值、效果量）
- 討論部分包含研究限制

## 專有名詞翻譯對照（選填）

**使用方式**：填入你研究領域的核心術語，格式為「中文翻譯（English）」。
LLM 會嚴格遵守下表的翻譯，未列出的術語會自動保持「中文（English）」格式。

| 英文術語 | 中文翻譯 |
|----------|----------|
| Reinforcement Learning | 強化學習 |
| Embodied Cognition | 體現認知 |
| Robustness | 穩健性 |
| Classifier | 量詞 |


> 請刪除範例列，填入你自己領域的術語。
