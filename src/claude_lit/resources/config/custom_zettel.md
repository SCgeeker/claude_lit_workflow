# Zettelkasten 卡片生成 - 自訂需求

此檔案定義生成 Zettel 卡片時的額外需求。
系統會自動載入此檔案（除非使用 --no-custom 跳過）。
**請根據你的研究領域修改此檔案。**

---

## 卡片撰寫風格

- 每張卡片以「一句話核心概念」清晰開頭
- 使用具體範例說明抽象概念
- 在「說明」區塊標註概念的認知層次（感知→理解→應用→分析→評估→創造）
- 若使用 `--slides-file` 載入投影片筆記，以**粗體標示**的概念為優先參考項目（非強制對應）

## 連結建立原則

- 優先建立與現有知識庫概念的跨論文連結
- 標註連結類型的認知關係（基礎知識、延伸概念、對比觀點）
- 同一論文內的卡片應形成連貫的知識網絡

## 術語處理

- 專業術語首次出現時附上英文原文
- 重要概念標註領域歸屬（如：認知科學、心理學、機器學習）

## AI 筆記要求

- 提出至少一個批判性問題
- 指出概念的應用限制或潛在爭議
- 連結到相關卡片以建立思考脈絡

## 專有名詞翻譯對照（選填）

**使用方式**：填入你研究領域的核心術語，格式為「中文翻譯（English）」。
LLM 會嚴格遵守下表的翻譯，未列出的術語會自動保持「中文（English）」格式。

| 英文術語 | 中文翻譯 |
|----------|----------|
| Reinforcement Learning | 強化學習 |
| Attention Mechanism     | 注意力機制 |
| Embodied Cognition | 體現認知 |
| Robustness | 穩健性 |


> 請刪除範例列，填入你自己領域的術語。
